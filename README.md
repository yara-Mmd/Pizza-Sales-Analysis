🍕 Pizza Sales Analysis Dashboard
##Project Overview
This project provides a comprehensive analysis of pizza sales data. The goal is to identify sales trends, top-selling pizzas, and peak order times to help optimize restaurant operations.
##Data Pipeline
SQL Server: Cleaned and queried the raw data using SQL to extract meaningful metrics.
Power BI Connection: Established a direct connection to SQL Server to import the data.
Visualization: Built an interactive dashboard to present the findings.
